StereoPano Editor

StereoPano Editor is a Cardboard Camera replacement for viewing, editing and exporting stereoscopic 360° panoramas. It is a native Android app (Java) plus a single-file desktop viewer/editor that runs in the browser (WebGL2). It works with .vr.jpg stereo panoramas and is built with Pixel phones and VR glasses such as the Goovis G3X Pro in mind.

Viewing

A stereo or flat 2D panorama viewer, with a folder browser, sorting and a language selector (EN, DE, FR, IT, ES, RU, UK).

Editing (originals are never modified, edits are saved as a new _clean.vr.jpg)

Seam fixing: drag the seam with the mouse or a finger, with a magnifier loupe and an automatic black-strip finder.
Removing objects by inpainting.
Realistic atmospheric effects such as leaves (including your own photo leaves), tuned to the scene’s lighting.
Colour and crop adjustments, audio, and undo.

Export

Stereo or flat images.
Rotating-panorama video.
YouTube 360 video, mono or stereo top-bottom, with spatial metadata.
Left and right eyes as separate images for an external editor, with import of the processed result.
